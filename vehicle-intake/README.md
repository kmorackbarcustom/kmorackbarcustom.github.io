# ระบบใบรับรถ - KMO RACK BAR CUSTOM

ระบบบันทึกข้อมูลรถเข้าซ่อมสำหรับร้านมอเตอร์ไซค์ พร้อมระบบสร้างใบรับรถ PDF และประวัติการรับรถ

## ฟีเจอร์หลัก
- **สร้างใบรับรถ:** กรอกข้อมูลลูกค้า รถ และสภาพรถ พร้อมแนบรูปภาพได้หลายรูป
- **บีบอัดรูปภาพ:** ระบบบีบอัดรูปภาพอัตโนมัติก่อน Upload เพื่อประหยัดพื้นที่ Storage
- **สร้าง PDF:** ดาวน์โหลดใบรับรถในรูปแบบ PDF ทันทีหลังบันทึก
- **ระบบประวัติ:** ค้นหาใบรับรถย้อนหลังได้จาก ทะเบียน, ชื่อลูกค้า หรือเบอร์โทรศัพท์
- **จัดการข้อมูล:** ดูรายละเอียด, ดาวน์โหลด PDF ซ้ำ, เลือกลบหลายรายการ หรือลบทีละรายการจากหน้าประวัติ

---

## วิธีการติดตั้ง (Setup)

### 1. เตรียม Supabase
1. สมัครใช้งาน [Supabase](https://supabase.com/) และสร้าง Project ใหม่
2. ไปที่เมนู **SQL Editor** และ Copy โค้ดจากไฟล์ `sql/setup.sql` ไปรันเพื่อสร้าง Table และ Storage Bucket
3. ไปที่เมนู **Project Settings > API** เพื่อเอา `Project URL` และ `anon key`
4. ค่าเริ่มต้นของ SQL อนุญาตให้ผู้ใช้หน้าเว็บอ่าน เพิ่ม และลบข้อมูลได้ เหมาะกับการใช้งานภายในร้านที่แชร์ลิงก์เฉพาะพนักงาน

### 2. ตั้งค่าโปรเจกต์ (Configuration)
1. Copy ไฟล์ `src/config.example.js` และเปลี่ยนชื่อเป็น `src/config.js`
2. แก้ไขไฟล์ `src/config.js` โดยใส่ค่าจาก Supabase ที่ได้ในขั้นตอนที่แล้ว:
   ```javascript
   export const SUPABASE_URL = 'https://YOUR_PROJECT_ID.supabase.co'
   export const SUPABASE_ANON_KEY = 'YOUR_ANON_KEY'
   ```

### 3. การ Deploy (GitHub Pages)
1. Upload ไฟล์ทั้งหมดขึ้น GitHub Repository
2. ไปที่ **Settings > Pages** ของ Repository
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ GitHub จะให้ URL สำหรับเข้าใช้งานระบบ

## โครงสร้างไฟล์
- `index.html`: หน้าสร้างใบรับรถใหม่
- `history.html`: หน้าดูประวัติและค้นหา
- `src/config.js`: ไฟล์ตั้งค่า (ห้ามลืมแก้!)
- `src/supabase.js`: จัดการติดต่อฐานข้อมูลและพื้นที่เก็บรูป
- `src/pdf.js`: จัดการสร้างไฟล์ PDF
- `src/main.js`: ควบคุม Logic หน้าสร้างใบรับรถ
- `src/history.js`: ควบคุม Logic หน้าประวัติ
- `src/styles.css`: จัดการหน้าตาและ UI (Responsive)

## ข้อแนะนำการใช้งาน
- การใช้งานบนมือถือ: สามารถถ่ายรูปและแนบเข้าสู่ระบบได้ทันที
- รูปภาพ: แนะนำให้แนบรูปสภาพรถรอบคัน (หน้า, หลัง, ซ้าย, ขวา) เพื่อเป็นหลักฐาน
- การค้นหา: หากต้องการดูรถทั้งหมดให้กดปุ่ม "ล้างการกรอง" หรือกดค้นหาโดยไม่กรอกอะไร
- การลบข้อมูล: สามารถติ๊กเลือกหลายรายการในหน้าประวัติแล้วกดลบ หรือกดเข้าไปในรายละเอียดเพื่อลบทีละรายการ ระบบจะลบทั้งข้อมูลและรูปภาพที่แนบไว้
- ความปลอดภัย: หากอัปโหลดระบบขึ้นเว็บสาธารณะ ข้อมูลในหน้าประวัติจะถูกอ่านได้ตาม policy ปัจจุบัน ควรเพิ่ม Supabase Auth หากต้องการจำกัดเฉพาะพนักงานร้าน
